# Настройка и запуск — «Киллер / Папарацци» (веб-версия)

Инструкция по установке, конфигурации и подключению ботов Telegram и VK.
Быстрый запуск сайта — в [README.md](../README.md); здесь — всё «продакшен»-важное.
Все команды выполняются из корня проекта (папки над этой).

---

## 1. Установка

```bash
python -m pip install -r setup/requirements.txt   # или ./start.sh — сделает сам
cp config.template.py config.py             # свой локальный конфиг (в .gitignore)
```

`config.py` **не** коммитится (в нём секреты). Все параметры имеют дефолты для
разработки и читаются из переменных окружения — в проде задавайте их через окружение.

---

## 2. Ключевые параметры (`config.py`)

| Параметр | Зачем | В проде |
|---|---|---|
| `SECRET_KEY` | подпись cookie-сессии | **ОБЯЗАТЕЛЬНО** задайте `SECRET_KEY` длинной случайной строкой (иначе сессии можно подделать) |
| `APP_BASE_URL` | из него боты собирают ссылку входа `/login?token=…` | публичный адрес сайта, напр. `https://killer.example.com` |
| `DB_NAME` | файл БД (одна «игра» = один файл) | путь к постоянному хранилищу; активную игру можно менять в «⚙️ Настройки игры» (указатель `data/active_db.txt`) |
| `ALLOW_DEV_LOGIN` | отладочный «вход как» `?user=` | **`0` в проде** (иначе можно войти за любого без ссылки) |
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота | см. раздел 4 |
| `VK_GROUP_TOKEN`, `VK_GROUP_ID` | ключ и id сообщества VK | см. раздел 5 |
| `LOGIN_TOKEN_BYTES` | длина токена ссылки входа | можно не трогать |

Пример для прода (Linux, переменные окружения):

```bash
export SECRET_KEY="$(python -c 'import secrets;print(secrets.token_urlsafe(48))')"
export APP_BASE_URL="https://killer.example.com"
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export VK_GROUP_TOKEN="vk1.a...."
export VK_GROUP_ID="123456789"
```

## 3. Первый запуск и доступ администратора

При первом старте автоматически создаётся особый пользователь **root** (его нельзя
удалить или разжаловать), а в лог печатается ссылка входа:

```
========================================================================
[root] Вход root-администратора (создайте через него обычного админа):
[root] http://127.0.0.1:8000/login?token=XXXXXXXX
========================================================================
```

1. Откройте эту ссылку — вы войдёте как root.
2. Через список игроков выдайте права администратора обычному пользователю
   (кнопка «👑 Выдать админа» в его карточке).
3. Дальше играют и администрируют через обычные аккаунты; root — «на всякий случай».

Ссылка печатается при каждом запуске; наберите `/start` боту, чтобы получить свою.

## 4. Telegram-бот

1. В Telegram напишите **@BotFather** → `/newbot`, задайте имя и username, получите
   **токен** вида `123456:ABC...`.
2. Впишите его в `config.py`: `TELEGRAM_BOT_TOKEN = "…"` (или переменной окружения).
3. Запустите бота **отдельным процессом** (рядом с веб-сервером):

   ```bash
   .venv/Scripts/python.exe tg_bot.py      # Windows
   .venv/bin/python tg_bot.py              # Linux/macOS
   ```

Что делает бот:
- `/start` — привязывает Telegram к аккаунту (identity, числовой id) и присылает
  **постоянную ссылку входа** на сайт;
- `/link КОД` — привязывает этот Telegram к уже существующему аккаунту (см. раздел 6);
- любое сообщение — пересылается администраторам;
- игровые уведомления сайт шлёт пользователям **сам** через Bot API
  (`core/tg_send.py`) — бот-процесс нужен только для приёма команд.

> Если `TELEGRAM_BOT_TOKEN` пуст, бот выключен, а на сайте остаётся **эмуляция
> чата** (`/` → `/chat/<username>`) — удобно для локальной разработки без токена.

> **Приветствие.** Текст на пустом экране чата (до первого `/start`, рядом с кнопкой
> «Начать») бот задаёт сам при запуске — `setMyDescription` в `tg_bot.py`. Отдельно
> настраивать в BotFather не нужно.

## 5. VK-бот (сообщество)

VK-бот работает от имени **сообщества** через **Bots Long Poll API**. Пошагово:

1. **Создайте сообщество** (или используйте существующее): vk.com → «Сообщества» →
   «Создать сообщество».
2. **Управление → Работа с API → Ключи доступа → Создать ключ.** Выдайте права:
   **«Управление сообществом»** и **«Сообщения сообщества»**. Скопируйте ключ —
   это `VK_GROUP_TOKEN` (начинается на `vk1.a...`).
3. **Управление → Работа с API → Long Poll API:**
   - включите **Long Poll API**, версия API — **5.199** (как в `config.py`);
   - на вкладке **«Типы событий»** включите **«Входящее сообщение»** (`message_new`).
4. **Управление → Сообщения → включите «Сообщения сообщества»** (иначе бот не сможет
   получать и отправлять личные сообщения).
5. **Узнайте id сообщества** (число): Управление → в адресе `.../club<ID>...`, либо
   через `https://api.vk.com/method/groups.getById?...`. Это `VK_GROUP_ID`
   (только число, **без** минуса).
6. Впишите в `config.py`:

   ```python
   VK_GROUP_TOKEN = "vk1.a...."
   VK_GROUP_ID = "123456789"
   ```
7. **(Рекомендуется) Приветствие и кнопка «Начать».** Это настройки **сообщества**
   (через API их не задать) — включите в UICP один раз:
   - **Управление → Сообщения → Настройки для бота → включите «Кнопка "Начать"».**
     Её нажатие присылает боту слово «Начать» — бот примет это как `/start` и вышлет
     ссылку входа.
   - Там же **«Приветствие»** — текст на пустом экране диалога. Рекомендуемый текст:

     > 🕵️ Игра «Киллер / Папарацци». Нажмите «Начать», чтобы получить ссылку для
     > входа на сайт.
8. Запустите VK-бота **отдельным процессом**:

   ```bash
   .venv/Scripts/python.exe vk_bot.py      # Windows
   .venv/bin/python vk_bot.py              # Linux/macOS
   ```

Что делает VK-бот (аналогично Telegram):
- сообщение **«Начать»** / `/start` — привязывает VK к аккаунту и присылает ссылку входа;
- `/link КОД` — привязка к существующему аккаунту (раздел 6);
- прочие сообщения — пересылаются администраторам;
- уведомления сайт шлёт через `messages.send` (`core/vk_send.py`).

> Если `VK_GROUP_TOKEN`/`VK_GROUP_ID` пусты — VK-бот выключен (остаётся эмуляция чата).

**Типичные проблемы:**
- бот не отвечает → проверьте, что включены «Сообщения сообщества» и тип события
  `message_new`, а у ключа есть право «Сообщения сообщества»;
- `messages.send` не доходит → пользователь должен сам первым написать сообществу
  (VK не даёт писать первым тем, кто не начинал диалог).

## 6. Привязка аккаунтов (Telegram ↔ VK)

Один человек может объединить Telegram и VK в **один** аккаунт (уведомления придут
в оба канала, вход — с любого) либо держать их **раздельно**.

**Объединить:**
1. Войдите на сайт (через любой канал) → **«Настройки профиля» → «Привязать
   аккаунт» → «Получить код привязки»**. Появится код, напр. `K7P2QМ`.
2. Напишите боту **другой** платформы: `/link K7P2QM`.
3. Готово — оба канала теперь ведут в один аккаунт.

**Разъединить:** там же, в «Настройках профиля», у нужного канала нажмите
**«Отвязать»** — канал станет отдельным аккаунтом (со своей ссылкой входа).

> Объединение отклоняется, если у привязываемого канала **уже есть игровая история
> или права админа** — чтобы не потерять данные. Сначала выйдите из игры этим
> каналом или используйте его отдельно.

## 7. Запуск всех процессов вместе

**Проще всего — одной командой** (веб + оба бота в одном окне, боты стартуют, только
если заданы их токены; у каждого свой префикс `[web]/[tg]/[vk]`):

```bash
./start.sh                 # создаст venv/зависимости и запустит всё
# или напрямую:
python run_all.py
```

При старте увидите строки вида «✅ Telegram-бот успешно подключён…» и
«✅ VK-бот успешно подключён…».

Либо каждый процесс отдельно (напр. как отдельные сервисы в проде):

```bash
python -m uvicorn app:app --host 0.0.0.0 --port 8000   # веб-сервер
python tg_bot.py                                        # Telegram-бот
python vk_bot.py                                        # VK-бот
```

Все процессы используют **одну и ту же БД** (SQLite в WAL-режиме — параллельный
доступ поддерживается). При смене активной игры (файла БД) перезапустите всё.

## 8. Данные и обслуживание

- `data/<игра>.db` — база; `data/active_db.txt` — указатель активной игры.
- `data/photos/` — фото-пруфы поимок; `data/chats/` — история эмуляции чата.
- `data/admin_log.txt` — журнал администраторов.
- Полный сброс БД — в «⚙️ Настройки игры → 💣 Полный сброс» (необратимо).

`config.py` и вся папка `data/` — в `.gitignore` (локальные, могут содержать секреты).
