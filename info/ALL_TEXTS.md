# ALL_TEXTS — сводка текстов для ревью (Киллер / Папарацци)

Единая таблица всех сообщений для ручного ревью и подготовки инструкций по замене
текстов веб-версии. Для каждого сообщения — 6 строк:

- **BK** — сообщение бота в стиле «Киллер» (из `killer_game_tg_bot_old`, старый коммит
  до переписывания в стиле «Папарацци»). Пусто, если аналога/сценария там не было.
- **BP** — сообщение бота в стиле «Папарацци» (из `killer_game_tg_bot`).
- **WK** — сообщение веб-версии в стиле «Киллер» (текущий `killer_game_web`).
- **WP** — сообщение веб-версии в стиле «Папарацци» (текущий `killer_game_web`).
- **UK** — ПУСТО: сюда вручную впишите обновлённый текст веб-версии для «Киллера».
- **UP** — ПУСТО: сюда вручную впишите обновлённый текст веб-версии для «Папарацци».

Соглашения:
- Внутренние переносы строк показаны как `\n` (одно сообщение = одна строка).
- Плейсхолдеры: `{name}` — имя игрока, `{victim}` — жертва, `{target}` — цель,
  `{admin}` — админ, `{murderer}`/`{new}` — поймавший/новый получатель зачёта,
  `{score}`/`{value}` — счёт, `{count}`/`{total}` — числа.
- Между блоками — по 3 пустые строки.
- Источник WK/WP — `core/mode.py` (режимно-зависимые) либо хардкод в `app.py` /
  `core/game.py` / `core/user.py` (режимно-независимые: тогда WK и WP совпадают).

Легенда источников для ориентира: BK=`killer_game_tg_bot_old`, BP=`killer_game_tg_bot`,
WK/WP=`killer_game_web`.

Маркер статуса — в начале каждой строки (один столбец слева; проставлен при закрытии
пункта TODO 30):
- ✅ — этот текст сейчас live в игре и работает.
- ✍🏻 — текст заменён в этой сессии: строка WK/WP — прежний вариант (более не live),
       соответствующая строка UK/UP — новый, уже применённый в коде.
- ❌ — такого сообщения/сценария в игре нет (напр. недостижимо из-за авто-переназначения
       целей, либо шаг объединён и отдельного сообщения нет).
- ⚪ — нейтральный: строки-источники BK/BP (эталон бота, не про наличие в вебе) и пустые
       строки UK/UP (правка не требовалась). Для ровного столбца.

Правило пары: в паре **WK↔UK** (и **WP↔UP**) галочка ✅ ровно у ОДНОЙ строки — у той,
что сейчас live. Если UK/UP заполнены (✅), то WK/WP помечаются ✍🏻 (прежний вариант).
