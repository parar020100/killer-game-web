## ✅ Готово

- Каркас FastAPI + Jinja2, БД SQLite (WAL), модели `game` / `user` / `identity`.
- Мультиплатформенные идентичности (tg/vk); журнал сообщений в файлах.
- Общий журнал администраторов (`/admin-log`).
- Страница-чат (лендинг) + эмуляция переписки с ботом.
- Вход по постоянной магической ссылке + подписанная cookie-сессия.
- Отладочный «вход как» (`?user=`) — разные игроки в разных вкладках.
- `root`-пользователь вместо `DEFAULT_ADMINS`: создаётся при первом запуске,
  ссылка входа печатается в лог; через него выдают права обычным пользователям.
- Регистрация через чат; полноценная форма с валидацией (имя + пароль + доп. вопросы).
- **Несколько** доп. вопросов при регистрации; ответы видны в списке и в профиле.
- Настройки игры хранятся в БД и правятся из UI («⚙️ Настройки игры»): пароль
  регистрации, контакт поддержки, файл правил, подтверждение поимок (CONFIRM_KILLS),
  доп. вопросы.
- Настройки профиля игроком: изменить имя и ответы на доп. вопросы, вкл/выкл
  личные уведомления; для админа — вкл/выкл ADMIN LOG (уведомления о событиях игры).
- Правила игры в HTML + кнопка «Правила».
- Адресная рассылка админом по группам (`/broadcast`).
- Ядро игры: круг `game_order` + раздача целей при старте.
- Поимки: сообщить → подтвердить/отклонить → выбывание → новая цель → победитель.
- Действия админа над игроком: устранить, оживить, подарить/отобрать жизнь (очередь
  + авто-оживление), сменить порядок (случайный **и** конкретный номер), изменить
  счёт, засчитать/отклонить поимку, удалить из игры / из системы.
- Жизненный цикл: пауза / продолжить / сброс / завершить + экран итогов, топ-3,
  победитель, промежуточные результаты (`/app/results`).
- Живое обновление страниц без F5 (мини-JS поллинг).
- Единый экран-дашборд (секции вместо вкладок); шапка в две колонки (статус / цель).
- Встроенный список игроков (кнопка-переключатель, состояние сохраняется);
  компактные карточки; полный набор полей и `killed_by` в раскрытой карточке.
- Живой поиск по списку игроков (подсветка совпадений + прокрутка), без кнопок.
- Скрытая цель (кнопка-спойлер) + лента уведомлений на дашборде.
- Постоянный набор кнопок у игрока и админа: недоступные по состоянию игры —
  серые, с подсказкой по клику (почему сейчас нельзя).
- Подтверждения («вы уверены?») на всех опасных действиях.
- Выход игрока из игры в любой момент.
- Секрет-пасхалка (рикролл: выбор RuTube / YouTube).
- Перезапуск приложения и полный сброс БД из настроек.
- `ALLOW_DEV_LOGIN` — простой флаг 0/1 в `config.py`.
- Единый постоянный набор игровых кнопок у игрока и не-игрока (недоступные — серые).
- Переключатель «меню админа» (сворачивает раздел управления); список игроков
  всегда в DOM (не «зависает» после снятия админки) и прокручивается в своём окне.
- Поиск по списку: Enter и кнопки ‹/› листают совпадения; клик по «кем пойман»
  находит того игрока; ссылка на профиль убившего в раскрытой карточке.
- Неподтверждённая поимка — красная строка-заявка прямо над карточкой «жертвы»
  (кнопки «Засчитать»/«Отклонить»); из меню карточки эти кнопки убраны.
- Действие админа «засчитать поимку другому» (переназначить очко за выбывшего).
- Выпадающий список файлов правил из папки `rules/`; компактные настройки профиля
  и игры в две колонки на широком экране.
- При добавлении новых доп. вопросов — уведомление игрокам без ответов.
- Профиль: «выйти на всех устройствах» (отзыв ссылок входа) и «забыть меня»
  (самоудаление учётки; root удалить нельзя).
- Оформление игры «Киллер» (заказные убийства, 🔪) / «Папарацци» (фотоохота, 📸):
  переключатель в настройках, все формулировки и иконки в `core/mode.py`
  (сводка пар — в `MODE_MESSAGES.txt`).
- Выбор активной игры по файлу БД (каждый файл — отдельная игра); указатель
  `data/active_db.txt`, применяется после перезапуска.
- Фото-пруф поимки: настройка вкл/выкл; при включении игрок прикладывает фото на
  странице поимки, файл сохраняется в `data/photos/`.
- Привязанные профили (tg/vk) в раскрытой карточке игрока — сначала Telegram, потом VK.
- «Скрыть меню админа» прячет и встроенный список игроков; карточка «Перезапуск
  приложения» — предпоследняя в настройках (перед полным сбросом).
- Полная синхронизация набора админ-кнопок над игроком/пользователем: один и тот же
  список кнопок для всех, недоступные — серые с подсказкой (в т.ч. «Удалить из
  системы» у игрока, игровые действия у не-игрока).
- Одностороннее сообщение админа игроку («✉️ Написать сообщение» в карточке —
  уведомление, как admin_msg в боте).
- Убраны отдельные страницы «Пользователи» и «Профиль пользователя»: клик по «кем
  пойман» находит игрока во встроенном списке и раскрывает его карточку.
- Поиск (с кнопками ‹/›) и подсказка списка — вне прокручиваемой части (закреплены),
  прокручивается только сам список карточек.
