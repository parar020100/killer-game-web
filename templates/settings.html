Параметры конкретного мероприятия: оформление, регистрация, правила, подтверждение и фото поимок, доп. вопросы.

🎭 Оформление игры

Меняет все формулировки и иконки. «Киллер» — заказные убийства (🔪 устранения); «Папарацци» — фотоохота на знаменитостей (📸 поимки).

🔑 Пароль регистрации

Если задан, игроки при регистрации должны ввести этот пароль. Оставьте поле пустым и сохраните, чтобы убрать пароль.

👋 Приветствие бота

Текст на пустом экране диалога (до нажатия «Начать»). По умолчанию — сгенерированный (сайт + ссылка на правила); можно отредактировать. Пустое поле вернёт текст по умолчанию.

В Telegram применится сразу; в VK его нужно вставить вручную (Управление → Сообщения → Настройки для бота → «Приветствие»; готовый текст бот пишет в файл intro.txt).

🗄️ Активная игра (файл БД)

🚪 Разлогинить всех пользователей

Закрывает все открытые сессии всех пользователей (сбрасывает входы во всех браузерах/на всех устройствах). Ссылки для входа не меняются — по ним можно войти заново. Пригодится, чтобы исправить ошибку и закрыть чужие открытые сессии. Ваша текущая сессия сохранится.
